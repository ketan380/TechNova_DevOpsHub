 REST API Documentation

          
Production-grade JSON endpoints with standardized HTTP status codes, structured error payloads, and interactive testing.

        

      


      
      

        

          

            GET /api/health
          

          
        

        
Returns service health status, application version, uptime, and UTC server timestamp.

        
curl -X GET http://localhost:5000/api/health

      


      
      

        

          

            GET /api/info
          

          
        

        
Returns detailed system metadata, Python version, platform specs, and registered endpoints.

        
curl -X GET http://localhost:5000/api/info

      


      
      

        

          

            POST /api/text/analyze
          

          
        

        
Analyzes text payloads and returns words, character counts (with/without space), lines, paragraphs, and byte size.

        
curl -X POST http://localhost:5000/api/text/analyze -H "Content-Type: application/json" -d '{"text": "DevOpsHub Docker Container"}'

      


      
      

        

          

            POST /api/json/validate
          

          
        

        
Validates JSON syntax, formats with custom indentation, and returns precise error diagnostics for invalid inputs.

        
curl -X POST http://localhost:5000/api/json/validate -H "Content-Type: application/json" -d '{"json_string": "{\"app\": \"DevOpsHub\"}", "indent": 2}'
